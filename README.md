# English-Russian Dictionary

Консольное приложение для изучения английских слов на Python.

## Функционал:
- Добавление новых слов и переводов
- Просмотр всего словаря
- Изменение слов и переводов
- Удаление слов

## Стек технологий:
- Python 3
- SQLite3 (встроенная база данных)

## Как запустить:
1. Склонируйте репозиторий.
2. Запустите файл `English_words_db.py` (или как называется твой главный файл).
